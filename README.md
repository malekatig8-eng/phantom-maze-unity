# 🎮 Phantom Maze

**Phantom Maze** is an in-development 3D exploration and maze prototype built with **Unity and C#**.

The project takes place in a forest ruins environment where the player can explore the level, move around the environment, jump, and interact with collectible rune objects.

## ✨ Features

- 🎮 3D player movement
- 🕹️ Keyboard and gamepad controls
- 🦘 Jumping and Rigidbody-based movement
- 📷 Third-person camera using Cinemachine
- 🌲 Forest ruins environment
- 💎 Collectible rune objects
- 💡 URP lighting and materials
- 🎨 Custom environment design

## 🛠️ Technologies

- **Unity 6**
- **C#**
- **Universal Render Pipeline (URP)**
- **Cinemachine**
- **Unity New Input System**
- **Git & GitHub**

## 🎮 Controls

| Action | Keyboard |
|---|---|
| Move | WASD / Arrow Keys |
| Jump | Space |

Gamepad controls are also supported through Unity's New Input System.
